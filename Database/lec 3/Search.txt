### Query 2

```

```

### Query 3

```

FROM employees
WHERE ROWNUM = 3;
```

Why does the first query work, while the second and third queries do not?

هنا بقي هنشوف الايه ال Subquery
هنضحك ع الداتا بيز هنخليها ترتب و تدي ارقام ROWNUM لكل السطر

SELECT * 
FROM (
       SELECT employees.*, ROWNUM as rn 
       FROM employees
     ) 
WHERE rn = 2;
